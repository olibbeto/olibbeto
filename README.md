### 🔐 90 Days of Cybersecurity — Live Log

I am actively following [MyFirstHack's](https://www.linkedin.com/company/myfirsthack/) 90-day curriculum from cybersecurity fundamentals to defensive practices — 30 minutes a day, concept by concept, documented publicly.

| Day | Topic | Key Takeaway |
|:---:|:------|:-------------|
| **01** | Data Breaches & HaveIBeenPwned | Verified personal email integrity; credential exposure awareness and breach monitoring. |
| **02** | The 4 Learning Traps | Consistency beats intensity; building sustainable study habits rather than burnout sprints. |
| **03** | Personal Security Audit | Executed a 5-step security audit; eliminated password reuse and enforced hardware/app-based 2FA. |
| **04** | Network Activity & Running Processes | Monitored background socket connections and network telemetry; computers are verifiable systems. |
| **05** | How Websites Actually Load | Analyzed DNS, TCP handshake, TLS negotiation, and third-party tracking script overhead. |
| **06** | IP Addresses & Location Leaks | Evaluated public IP leakage, ISP routing, and network fingerprinting on every connection. |
| **07** | DNS Hierarchy & Resolution | Inspected resolver chains, DNS cache poisoning risks, and encrypted DNS (DoH/DoT). |
| **08** | Password Entropy & Mathematics | Demonstrated why 20-character passphrase length mathematically outperforms short "complex" passwords. |
| **09** | Phishing Vectors & Defense | Analyzed the root cause of 80%+ breaches: urgency traps, hover-verification, multi-channel auth. |
| **10** | Personal Data Mapping & GDPR | Mapped PII across identity providers and exercised data subject access requests (DSAR). |
| **11** | Third-Party Scripts & Attack Surface | Assessed how external dependencies and CDNs expand client-side exploit surfaces. |
| **12** | HTTPS, TLS Certificates & Trust | The lock icon guarantees transport encryption, not inherent safety; phishing sites use TLS too. |
| **...** | *In Progress* | Daily updates posted publicly on LinkedIn! |
